## 구현 상태 표기

| 표기      | 의미                                           |
| --------- | ---------------------------------------------- |
| 구현      | 실행 코드가 존재하며 제공 범위가 문서에 명시됨 |
| 부분 구현 | 요구사항 중 일부만 실행 가능                   |
| 미구현    | 인터페이스·스키마·화면 구조 또는 설계만 존재   |
| 미검증    | 해당 환경에서 실행 결과를 확인하지 않음        |

기능 구현 여부와 환경 검증 여부는 구분합니다. 예를 들어 Compose 설정이 존재하더라도 실제 기동 결과가 없으면 해당 실행 환경은 미검증으로 기록합니다.
