# 인수 시험 명세

이 문서는 수집·판정·검색·설명·보고서가 구현된 이후 수행할 통합 시험을 정의합니다. 현재 자동화 테스트의 통과 수는 아래 인수 시험의 완료를 의미하지 않습니다. 현재 실행 결과는 [검증 기록](../../docs/verification.md)에 구분되어 있습니다.

## 시험 범위

| 구분      | 시나리오                                             | 수용 조건                                     |
| --------- | ---------------------------------------------------- | --------------------------------------------- |
| 자산·수집 | 허용된 Ubuntu 서버의 OS·패키지 정보 수집             | 원본 값과 저장값 일치, 시점·출처·완전성 기록  |
| 판정      | 동일 CVE·자료 기준본의 취약·수정 상태 비교           | 공식 조건에 따른 결과와 비교 근거 추적        |
| 경계 상태 | 부분 수집, 알 수 없는 출처, 미지원 패키지, 자료 부재 | 미확인 상태를 비영향으로 처리하지 않음        |
| 자료 갱신 | 중복 자료, 갱신 실패, 수정·상충 자료                 | 이전 근거 보존, 사용 기준본과 실패 상태 표시  |
| 수집 제한 | 호스트 키 불일치, 연결 실패, 허용하지 않은 명령      | 실행 차단, 구분된 오류, 자격 증명 비노출      |
| 설명·인용 | 선택 자산의 판정 설명과 문서 근거 제공               | 자산 범위 일치, 실제 인용, 구조화된 판정 보존 |
| 모델 장애 | 추론 실패·시간 초과·불충분한 근거                    | 기존 판정 조회 유지, 오류·한계 명시           |
| 인증      | 계정·세션·접근 범위 검사                             | 허용되지 않은 자산 조회·작업 차단             |
| 보고서    | 고정된 분석 기준의 Markdown 생성                     | 화면·보고서의 판정·출처·기준 시점 일치        |
| 실행 재현 | 새 환경 설치, 데이터 복원, 동일 사례 실행            | 절차에 따른 기동과 결과 재현                  |

## 결과 기록

각 실행에는 다음 정보를 포함합니다.

| 항목      | 기록 내용                                          |
| --------- | -------------------------------------------------- |
| 실행 식별 | 사례 ID, 실행 시각, 코드 버전                      |
| 환경      | OS·패키지·DB·모델·색인·규칙 버전                   |
| 입력 기준 | 자산 스냅샷, 보안 자료 기준본, 문서·설치 파일 해시 |
| 기대 결과 | 처리 상태, 판정, 인용, 오류 조건                   |
| 실제 결과 | 응답·저장값, 요청·작업 ID, 소요 시간               |
| 평가      | 일치 여부, 재현 절차, 미해결 제한 사항             |

판정 평가는 공식 근거와 설치 상태를 대조합니다. 설명 평가는 링크의 존재뿐 아니라 주장과 인용 내용의 일치를 확인합니다. 성능은 실제 실행 환경과 표본 조건을 함께 기록하며 가상 자료의 결과로 일반적인 정확도나 성능을 보장하지 않습니다.
