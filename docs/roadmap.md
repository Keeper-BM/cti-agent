# 개발 예정 기능

이 문서는 현재 미구현 기능과 기술적 선행 조건을 정리합니다. 각 항목은 제공 기능이 아니며 완료 상태는 실행 코드와 검증 결과를 기준으로 갱신합니다.

## 제공된 개발 기반

단일 개발 실행기, 연결된 가상 입력·기대 결과와 패키지·보안 자료 계약을 제공합니다. 첫 화면·계약 변경은 실제 SSH·모델 없이 확인할 수 있습니다. 구현을 확장할 때에는 하나의 지원 릴리스·패키지 조합에 대해 수집부터 판정·근거 표시까지 연결하고 공식 기준 사례로 검증합니다. 벡터 검색, 모델, 예약 갱신과 운영 기능은 해당 흐름이 준비된 뒤 필요한 범위에서 추가합니다.

## 기반 기능

| 영역        | 현재 상태                                 | 필요한 구현                                        |
| ----------- | ----------------------------------------- | -------------------------------------------------- |
| 운영 인증   | 개발용 공통 토큰                          | 계정·세션, 자산 접근 검사, 감사 기록               |
| 자산 입력   | 수동 등록·조회·활성 상태 변경             | 일반 수정, CSV·JSON 입력 검증, 이력 보존·삭제 정책 |
| 접속 프로필 | 미구현                                    | 접속 대상·포트·계정·호스트 키, 비밀정보 분리       |
| 작업 처리   | 연결 확인, 상태 조회, 중단 작업 실패 처리 | 외부 I/O의 시간 제한·취소·재시도·실행 복구 정책    |

## 데이터 수집과 저장

| 영역           | 선행 조건                              | 필요한 구현                                    |
| -------------- | -------------------------------------- | ---------------------------------------------- |
| 서버 수집      | 접속 프로필, 허용 대상 정책, 시험 환경 | 고정 읽기 명령, 출력 검증, 부분 수집·실패 처리 |
| 자산 스냅샷    | 수집 계약, 저장 스키마                 | OS·전체 패키지 버전·출처·완전성·수집 시점 보존 |
| 공식 자료 수집 | 지원 릴리스·패키지와 공식 표본 확인    | Ubuntu·보충 자료 수집, CVE 연결, 정규화        |
| 자료 갱신      | 원문·문서 버전 저장                    | 중복 방지, 갱신 시점, 실패·상충 자료 처리      |

## 판정과 결과 조회

| ------------- | ------------------------------------- | ------------------------------------------ |
| 영향 판정     | 자산 스냅샷, 공식 자료, 패키지 대응표 | 버전·조건 대조, 처리 상태·판정·이유 저장   |
| 우선순위      | 판정과 CVSS·KEV·공개 범위             | 누락값 구분, 근거가 있는 우선순위 구성     |
| 결과 API·화면 | 판정 저장과 조회 계약                 | 필터, 상세 근거, 수정·완화 정보, 상태 비교 |

## 검색과 설명

| 영역      | 선행 조건                   | 필요한 구현                                |
| --------- | --------------------------- | ------------------------------------------ |
| 추론 연결 | 모델·실행 환경 검증         | 모델 호출, 응답 형식, 시간 초과·장애 처리  |
| 문서 검색 | 공식 문서 버전, 임베딩 선정 | 문서 분할, 색인, 자산·CVE·릴리스 범위 검색 |
| 질의응답  | 판정 조회, 검색, 모델 연결  | 자산 범위 제한, 인용 검증, 불확실성 표시   |
| 보고서    | 고정된 분석 결과와 근거     | 생성·조회·Markdown 출력, 기준 시점 보존    |

## 기술 결정 항목

- 분석 대상 Ubuntu 릴리스와 검증 가능한 Apache·MySQL 패키지 조합
- 바이너리·소스 패키지 매핑과 설치 출처의 확인 기준
- SSH 허용 대상·네트워크·포트·호스트 키 정책
- 모델·임베딩·추론 API·GPU 환경과 성능 기준
- 문서·분석·보고서 이력의 보존 및 삭제 정책
- 백업·복원, 운영 인증, 배포 환경과 컨테이너 이미지 고정 방식

## 통합 검증

수집·판정·질의·보고서를 같은 분석 기준으로 연결한 뒤 [인수 시험](../tests/acceptance/README.md)을 수행합니다. 설치 상태별 판정, 공식 인용, 연결·갱신·추론 실패, 접근 제한, 새 환경 실행과 복원을 확인하고 실측 결과를 기록합니다.
