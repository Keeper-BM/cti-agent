# 대응 보고서 생성·저장·다운로드

완료된 분석 한 건을 보고서로 생성합니다. 패키지 입력·판단·버전 비교·위험 정보·공식 출처를 복사해 고정하며, 선택하면 각 결과의 최신 성공 AI 설명도 포함합니다. 보고서는 원본 분석을 변경하지 않고 새 이력으로 저장됩니다.

## 사용 방법

1. API·웹·Worker를 실행합니다. 기존 DB에는 `alembic upgrade head`로 `0006`을 적용합니다. `scripts/dev.py`는 시작 시 마이그레이션을 적용합니다.
2. **취약점 분석**에서 완료된 분석의 **보고서 만들기**를 누릅니다. 또는 **대응 보고서** 메뉴에서 자산과 완료된 분석을 선택합니다.
3. **AI Summary 포함** 여부를 선택합니다. 기본은 미포함입니다.
4. **보고서 생성**을 누르고 이력에서 완료 상태를 확인합니다.
5. 미리보기에서 요약·패키지·CVE별 결과·근거·AI 설명을 확인합니다. 패키지·CVE 검색과 페이지 이동은 미리보기만 바꿉니다.
6. **Markdown 다운로드**로 보고서 전체 내용을 `.md` 파일로 내려받습니다. UTF-8 텍스트이며 한글을 지원하는 Markdown 뷰어에서 열 수 있습니다.

완료되지 않은 분석은 선택할 수 없습니다. 비활성 자산의 완료된 과거 분석도 문서로 만들고 조회할 수 있습니다. 보고서 조회·다운로드·생성은 자료 수집, 재분석, LLM 호출을 수행하지 않습니다. PDF·DOCX와 여러 분석을 합치는 기능은 이번 범위에 포함하지 않습니다.

## 포함하는 내용

- 분석 당시 자산 이름, OS·아키텍처, 패키지 확인·입력 시각, 분석 완료 시각
- 입력 목록 완전성, 가상 여부, 분석 당시 경고
- 입력 패키지 목록과 바이너리·소스 버전, 설치 출처 확인 수준
- CVE별 버전 비교, 최종 판단, 처리 상태, 판단 이유·추가 확인 사항
- 공급자별 CVSS 버전·점수·벡터, KEV 등재 상태
- 판정 근거의 공식 링크·발췌·원문 ID, 자료 기준본·수집 시각·해시
- 포함을 선택한 경우 고정한 AI 설명·인용·모델·생성 시각·설명의 한계
- 분석·패키지 입력·판정 규칙·보고서 양식 식별 정보

자산 주소·담당자·SSH 접속정보·API 키를 보고서 필드로 포함하지 않습니다. 자산 이름과 패키지 환경은 포함되므로 파일 전달 범위는 사용자가 결정합니다.

## 집계와 해석

**버전 비교**와 **최종 판단**을 별도로 집계합니다. `BELOW_FIX` 건수를 취약 확정 건수로 표시하지 않습니다. JSON의 설치 출처는 미검증이므로 기존 분석의 `NEEDS_REVIEW`와 그 이유를 유지합니다.

‘입력 패키지 수’, ‘패키지별 결과 수’, ‘중복을 제외한 CVE 수’는 서로 다른 집계입니다. 동일 CVE가 여러 패키지에 연결되면 결과는 각각 보존하되 CVE 수는 한 번만 셉니다. KEV 등재 CVE 수도 중복을 제외합니다.

`NO_MATCHING_RECORD`, `OUT_OF_SCOPE`, `PARTIAL_COLLECTION`, `NOT_INSTALLED`, `COLLECTION_FAILED`에는 취약 여부 판정값을 부여하지 않습니다. CVSS 미제공은 0과 다르며, KEV 미등재·미수집은 악용 없음의 근거가 아닙니다. 가상 입력은 표지와 확인 사항에 표시합니다.

보고서는 패키지 기준 결과입니다. 실행 중인 서비스, 재시작 여부, 자산 전체의 안전을 보장하지 않습니다. 자동 패치·설정 변경은 수행하지 않습니다. [분석 범위](assessment.md).

## AI 설명 포함 기준

요청이 접수될 때 해당 분석의 각 결과별 **가장 최근 성공한 설명**을 선택합니다. 실패·대기·생성 중 설명은 포함하지 않습니다. 저장된 성공 설명이 없는 결과에 대해 새 설명을 생성하거나 내용을 만들어 넣지 않습니다. 포함 옵션이 켜져 있어도 성공 설명이 없으면 0건으로 표시합니다.

선택한 설명의 기준값·판정·버전·CVE와 인용 참조가 분석 범위와 일치하는지 검사합니다. 모델·생성 시각·인용·설명 한계를 함께 복사합니다. AI가 쓴 설명과 저장된 분석 원본을 구분하며, 인용 ID 검사는 문장 전체의 사실성을 증명하지 않습니다. [AI 설명의 검사 범위](ai-explanations.md).

## 고정 시점·저장·실패 처리

접수 시 `ReportContent` 전체를 복사해 `reports.input_payload`에 저장하고 SHA-256을 계산합니다. 자산 이름은 현재 값이 아닌 분석 당시 이름을 사용합니다. 요청 뒤 자료가 갱신되거나 새 AI 설명이 생겨도 이미 고정한 내용은 바뀌지 않습니다.

Worker의 `REPORT` 작업은 저장된 입력 해시와 양식 버전을 확인한 후 같은 내용으로 미리보기 데이터와 Markdown을 생성합니다. 완료 결과·파일·해시·작업 성공 상태는 하나의 DB 트랜잭션으로 저장합니다. 실패하면 신규 파일을 공개하지 않고 이전 보고서와 분석은 유지합니다. Worker 중단 시 미완료 작업은 기존 정책대로 실패 처리하며 자동 재실행하지 않습니다.

입력과 완성 파일 각각 최대 16 MiB를 허용합니다. 제한을 넘기면 `REPORT_SIZE_LIMIT` 오류를 표시합니다. 일부 결과를 조용히 누락하는 방식으로 파일을 만들지 않습니다. 미리보기는 패키지·결과 20건, AI 설명 5건씩 페이지를 나누며 다운로드는 전체 내용입니다.

Markdown의 외부 문자열은 표·제목·HTML·이미지 등을 삽입하지 못하도록 이스케이프합니다. 링크는 자격정보가 없는 HTTP(S) 주소만 사용합니다. 화면은 HTML 문자열 실행 없이 구조화된 데이터를 React 텍스트로 표시합니다. 다운로드에는 `Content-Disposition: attachment`, `X-Content-Type-Options: nosniff`, `X-Content-SHA256`을 설정합니다. 파일명은 사용자 입력 대신 보고서 UUID로 만듭니다.

## API

모든 경로는 `/api/v1` 기준이며 개발용 토큰이 필요합니다.

| 메서드 | 경로                     | 동작                                                                                       |
| ------ | ------------------------ | ------------------------------------------------------------------------------------------ |
| POST   | `/reports`               | `{"analysis_id":"UUID","include_ai_explanations":false}`, `Idempotency-Key` 필수. 202 접수 |
| GET    | `/reports`               | `asset_id`, `analysis_id` 선택 필터. 기본 10건, `limit` 1~100, `offset` 0 이상             |
| GET    | `/reports/{id}`          | 작업·요약·완료된 미리보기 데이터. 생성 전·실패 시 `content=null`                           |
| GET    | `/reports/{id}/markdown` | 저장한 UTF-8 Markdown 파일. 미완료·실패는 409                                              |

같은 요청 키·분석·옵션은 기존 보고서를 반환합니다. 같은 키를 다른 작업·분석·옵션에 재사용하면 409입니다. 새 요청 키는 같은 분석에 대한 새 보고서 이력을 만듭니다. 이전 미구현 계약의 `analysis_ids` 배열은 받지 않습니다.

`reports` 기능 플래그는 `true`입니다. 질문·SSH 수집·공식 패키지 검증도 별도 API로 제공하며, 보고서에는 같은 분석의 CVE 설명과 검증 근거를 포함합니다. 다중 분석의 자유 질문 답변은 보고서에 자동 삽입하지 않습니다.

자동 검사와 실제 HTTP 실행 결과, 브라우저 검증의 제한은 [검증 기록](verification.md)에 구분했습니다.

새 보고서는 CVE별 대응 안내와 연결된 공식 파일 검증 이력도 고정합니다. 과거 보고서의 저장된 Markdown과 해시는 유지합니다.
