# 기능 명세

## 목적과 적용 범위

CTI Agent는 Ubuntu 서버의 설치 환경과 공식 보안 자료를 대조하여 공개 취약점의 영향 여부, 판정 근거, 대응 정보를 제공하는 애플리케이션입니다. 주요 사용 대상은 Ubuntu 자산을 관리하는 시스템 관리자와 보안 운영자입니다.

현재 분석 범위는 Ubuntu 22.04·24.04의 apache2·mysql-8.0 소스 패키지입니다. 저장 입력의 버전 비교·판단 제한·공식 근거 이력을 구현했습니다. JSON 출처 미검증과 조건 미확인 시 확정 판단을 제한합니다. [상세 범위](assessment.md).

이 문서의 요구사항은 목표 동작을 정의합니다. 현재 구현 여부는 다음 표에 구분하며, 구체적인 HTTP 제공 범위는 [API 계약](api-contracts.md)을 따릅니다.

## 기능 요구사항

| ID      | 기능        | 현재 제공 범위                                           |
| ------- | ----------- | -------------------------------------------------------- |
| REQ_001 | 자산 관리   | 등록·조회·일반 수정·비활성화·고정 SSH 프로필             |
| REQ_002 | 환경 수집   | JSON·CSV·SSH·불변 인벤토리, 공식 파일 검증·근거          |
| REQ_003 | 공식 자료   | 다섯 출처의 제한된 수집·정규화·원문·해시·이력            |
| REQ_004 | 영향 판단   | 제한 범위의 버전·출처·공식 조건 비교, 미확인 제한        |
| REQ_005 | 위험도 조회 | 판단·비교·CVSS·KEV·근거·검색·필터                        |

| REQ_007 | 인사이트    | 한 CVE 설명, 선택 분석의 TF-IDF 검색·질문·인용·이력      |

| REQ_009 | 입력 검증   | 필드·형식·중복·JSON·CSV·서버 소유 신뢰 수준 검사         |
| REQ_010 | 작업 관리   | 수집·검증·분석·질문·설명·비교·보고서 큐·오류             |

| REQ_012 | 보고서      | 분석·CVE 설명·검증 근거 고정, 미리보기·Markdown 다운로드 |
| REQ_013 | 운영 기록   | 로그인·접근 거절·자산·권한·작업 감사 기록                |
| REQ_014 | 실행 재현   | 잠금 의존성·마이그레이션·로컬·Compose, SQLite 백업·복원  |

계정·세션·관리자/담당자/조회자 역할·자산 권한을 제공합니다. 자산은 비활성화하고 이력을 보존하며 물리 삭제·자동 정리는 제공하지 않습니다. 구현 여부와 환경·정확성 검증은 다릅니다. [실제 검증 기록](verification.md)과 [시연 순서](demo-guide.md)를 확인하세요.

## 개발용 시험 흐름

현재 별도 시험 예제 API·화면과 CLI가 가상 인벤토리, 정규화된 보안 자료, 기대 판정과 인용을 연결합니다. 고정 기대 결과를 읽고 참조 일관성을 검사하며 실제 수집·판정·설명 기능의 구현 상태에는 포함하지 않습니다. 자세한 내용은 [시험 예제 안내](development-example.md)를 참고합니다.

## 목표 처리 흐름

```text
자산 등록 → 환경 수집 → 스냅샷 저장 → 공식 자료 대조
        → 판정·근거 저장 → 문서 검색·설명 생성 → 웹·보고서 제공
```

공식 보안 자료는 독립적으로 수집·갱신하고, 각 분석이 사용한 자료 버전을 보존합니다. 취약점 인사이트와 보고서는 이미 저장된 분석 결과를 참조하며 동일한 기준본의 판정·근거를 표시합니다.

## 수집 및 보안 자료

서버 수집은 등록된 접속 프로필, 허용 대상 검증, SSH 호스트 키 확인, 고정된 읽기 전용 명령을 전제로 합니다. OS 식별값, 바이너리·소스 패키지명, 전체 버전, 설치 상태, 출처 확인 수준과 수집 완전성을 구분해 저장합니다.

현재 SSH 수집은 dpkg 조회값과 APT 참고 출력을 보존합니다. SSH 수집만으로는 `UNKNOWN`을 유지합니다. 별도 공식 파일 검증은 서명·패키지 해시·설치 파일을 대조하고 일치한 패키지의 새 기록에 `OFFICIAL_MATCH`를 부여합니다. [연결 준비·구현 범위·검증 한계](ssh-collection.md).

부분 수집과 실패를 완전한 목록으로 취급하지 않습니다. 수집 실패 시 이전 정상 스냅샷을 보존하고 실제 사용한 자료의 시점과 최근 실패 상태를 함께 표시하도록 설계합니다.

| 자료                          | 분석에서의 용도                       |
| ----------------------------- | ------------------------------------- |
| Ubuntu CVE·USN                | 릴리스·패키지별 영향과 수정 근거      |
| Ubuntu OVAL·패키지 메타데이터 | 조건 대조와 패키지 대응 검증          |
| NVD                           | CVE 설명·점수 등 보충 정보            |
| CISA KEV                      | 대응 우선순위에 필요한 악용 확인 정보 |
| Apache·Oracle 공식 공지       | 제품 조건과 수정·완화 안내 보완       |

수집 결과에는 원문, 출처 유형, 주소, 수집 시각, 제공되는 공개·수정 시각, 원문 해시와 기준본을 연결합니다. 다섯 공식 출처를 사용자의 수집 요청에 따라 가져오며, 갱신 실패 시 이전 자료를 유지합니다. 현재 수집 범위와 제한은 [공식 CVE 자료 안내](security-sources.md)에 명시합니다. 저장 입력과 공식 자료를 연결하는 제한 범위 분석을 제공합니다.

## 판정 원칙

판정 단위는 자산 스냅샷, 설치 패키지, CVE, 보안 자료 버전의 조합입니다. 소스·바이너리 패키지를 구분하고 epoch와 배포판 수정 번호를 포함한 전체 버전을 보존합니다. 버전 비교는 Debian 버전 규칙을 따르는 구현으로 검증합니다.

| 판정           | 의미                                           |
| -------------- | ---------------------------------------------- |
| `AFFECTED`     | 적용 가능한 공식 영향 조건에 해당              |
| `FIXED`        | 해당 CVE의 공식 수정 조건을 설치 패키지가 충족 |
| `NOT_AFFECTED` | 해당 환경에 적용되는 명시적 비영향 근거가 있음 |
| `NEEDS_REVIEW` | 입력·출처·조건·근거가 부족하거나 상충          |

판정값과 처리 상태를 분리합니다. `OUT_OF_SCOPE`, `NOT_INSTALLED`, `NO_MATCHING_RECORD`, `COLLECTION_FAILED`, `PARTIAL_COLLECTION`은 영향 없음으로 변환하지 않습니다. CVSS 미제공도 점수 0과 구분합니다.

설치 출처, 릴리스 또는 필요한 추가 조건을 확인하지 못한 경우 확정 결과를 제한합니다. 외부 공개 여부나 서비스 실행 상태는 운영 참고 정보이며 패키지의 수정 여부와 분리합니다. 동일 입력·자료·규칙 버전은 동일한 판정 결과를 생성해야 합니다.

## 검색·설명·보고서

근거 검색은 선택 자산, CVE, 릴리스와 분석 기준으로 범위를 제한합니다. 문서 조각은 원문 버전과 위치를 참조하며, 색인 버전을 기록합니다. 현재 로컬 희소 TF-IDF를 사용하며 신경망 임베딩은 사용하지 않습니다.

LLM은 구조화된 판정과 검색 근거를 설명합니다. 판정 상태·패키지 버전·자료 시점은 백엔드의 원본 값을 사용합니다. 출력의 인용 ID가 실제 제공한 문서에 존재하는지 검증하고 출처 주소는 저장된 메타데이터에서 가져옵니다.

근거가 부족하면 한계를 표시하고, 추론 서버 장애 시 기존 판정·공식 근거 조회를 유지하도록 설계합니다. 생성 모델은 학교 LLM API의 Qwen/Qwen3.8-Flash-Next-FP8을 로컬 설정에 선택했으며, 한 CVE의 설명 연동은 구현했습니다. 선택한 완료 분석의 TF-IDF 근거 검색과 질문 답변을 구현했습니다. 보고서는 접수 시점의 분석 결과와 출처·선택한 AI 설명을 고정해 저장하고 미리보기·Markdown 다운로드로 제공합니다. [보고서 안내](reports.md).

## 접근 및 실행 경계

현재 계정 모드는 사전 발급 계정, 세션, 자산별 접근 검사, 감사 기록을 포함합니다. 외부 연결은 등록된 대상과 출처로 제한하고 수집 시간·출력량·요청량을 제어해야 합니다. 비밀키는 일반 자산 데이터, 응답, 로그와 분리해 관리합니다.

입력 문서와 모델 출력은 실행 명령으로 사용하지 않습니다. 자동 패치, 설정 변경, 서비스 재시작, 임의 명령 실행, 공격 수행, 무단 스캔은 제품 기능 범위에 포함하지 않습니다.

다른 운영체제, 모든 Ubuntu 패키지·커널의 포괄적 분석, 미검증 설치 경로, 실시간 침해 탐지, 클라우드 자산 자동 등록, 다중 조직, 고가용성, 모델 추가 학습은 현재 범위에 포함하지 않습니다. Nginx는 현재 웹 제공·프록시 구성에 사용되며 취약점 판정 대상으로 구현된 것은 아닙니다.

## 검증 기준

수집값과 저장값의 일치, 동일 기준의 판정 재현, 공식 근거 추적, 미확인 상태 표시, 인용의 실제 존재, 장애 시 결과 보존, 새 환경 실행을 확인합니다. 성능과 정확도는 실제 환경·자료·모델을 기록한 시험 결과로 평가합니다.

통합 검증 시나리오는 [인수 시험 명세](../tests/acceptance/README.md), 수행한 검사 결과는 [검증 기록](verification.md)에 기록합니다.
