# 구현 범위와 다음 우선순위

2026-11-11 기준으로 교수님 시연의 핵심 흐름인 **Ubuntu 수집 → 공식 CVE 분석·근거 → 대응 안내·학교 API 설명/질문 → 보고서 다운로드**를 최우선 인수 대상으로 삼습니다. 실행 결과는 [검증 기록](verification.md), 따라 할 절차는 [시연 안내](demo-guide.md)에 둡니다.

## 구현된 범위

자산 관리·JSON/CSV·SSH 수집, 공식 패키지 파일 검증, 다섯 출처의 자료 관리, 제한 범위 Ubuntu 판단, 조치 안내, 같은 보안 자료 기준의 전후 비교, CVE 설명·선택 분석 질문·TF-IDF 검색, Markdown 보고서, 계정·자산 권한·감사, 백업·별도 복원을 연결했습니다.

구현 완료는 모든 서버·CVE의 정확성이나 운영 배포 안전을 보증하지 않습니다. 기존 이력은 보존하며 각 기능의 실제 시험·남은 한계를 문서에서 구분합니다.

## 시연 이후 검토할 확장

- USN 본문·OVAL 전체 조건 해석과 더 많은 모듈·실행 설정 확인
- 신경망 임베딩·다국어 의미 검색, 검색 품질·인용 주장 평가 확대
- PDF 출력과 보고서 표현 형식 확대
- 추가 Ubuntu 실제 서버·아키텍처·원격 환경과 별도 배포 환경
- 필요성 확인 후 예약 수집·다중 Worker·보관 정책·운영 배포 보강

현재 자동 패치·설정 변경·서비스 재시작·공격·무단 스캔은 제품 범위 밖입니다. 모든 패키지·다중 조직·고가용성·모델 학습을 이번 시연의 완료 조건으로 잡지 않습니다.
