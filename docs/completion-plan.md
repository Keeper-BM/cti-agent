# 남은 기능 구현 및 인수 계획

2026-11-10 사용자 요청: 앞으로 필요한 기능을 전체 구현한다. 기존 명세의 Ubuntu 22.04·24.04, Apache2·MySQL 범위와 자동 패치·공격·운영체제 변경 제외 원칙을 유지한다. WSL을 사용하지 않으며 Windows 가상화 설정 변경이나 재부팅이 필요하면 먼저 알린다.

## 작업 목록

| 단계             | 결과물                                                       | 완료 조건                                                           | 상태                     |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------------- | ------------------------ |
| 공식 패키지 검증 | 서명된 Ubuntu 저장소와 설치 파일 대조, 결과·근거·새 인벤토리 | 일치·차이·자료 부재·변경 중인 패키지 구분, 검증 범위 밖의 확정 방지 | 구현·실제 VM 시험 완료   |
| 자산·입력 관리   | 자산 수정, CSV 입력, 감사 기록                               | 검증·이력 보존·기존 JSON 호환                                       | 구현·자동/HTTP 시험 완료 |
| 대응 안내        | CVE별 공식 수정 정보와 확인 절차                             | 출처·판단에 맞는 안내, 자동 실행 없음                               | 구현·자동/HTTP 시험 완료 |
| 상태 비교        | 같은 자산·보안 기준본의 이전/이후 분석 비교                  | 버전·판단·패키지 추가/부재 구분, 서로 다른 기준의 단정 방지         | 구현·자동/HTTP 시험 완료 |
| 취약점 인사이트  | 범위가 고정된 근거 검색과 학교 API 질문·답변                 | 인용 추적, 판단 원본 보존, 근거 부족·모델 장애 처리                 | 구현·자동/HTTP 시험 완료 |
| 계정·접근 제어   | 로그인·세션·역할·자산 접근 권한                              | 모든 읽기·쓰기 경로의 권한 검사와 실패 기록                         | 구현·자동/HTTP 시험 완료 |
| 운영·통합        | 작업 상태, 문서·API 타입, UI 연결, 실행·복원 절차            | SQLite·PostgreSQL·Compose 및 실제 VM 인수 시험, 미검증 사항 명시    | 구현·자동/HTTP 시험 완료 |

이 표는 실행 결과를 확인한 뒤 갱신한다. 코드 존재만으로 인수 완료로 표시하지 않는다. 기존 데이터·설명·보고서는 유지하고 마이그레이션 전 백업한다. 대용량 의존성·모델·검증 캐시는 D 드라이브에 둔다.

## 2026-11-11 최종 인수

핵심 시연 네 단계의 실제 Vite/API/별도 Worker/Ubuntu/학교 API/보고서 흐름을 통과했습니다. 기존 데이터·보고서 해시를 보존하고 백업의 별도 복원도 확인했습니다. 전체 자동시험 258개, 별도 PostgreSQL 1개, 프론트엔드 8개가 통과했습니다. 구체적인 검증과 미완료 범위는 [검증 기록](verification.md)에 기록했습니다.

사용자의 우선순위에 따라 USN·OVAL 전체 해석·신경망 임베딩·PDF·추가 배포 환경 확장은 이번 완료 범위에 넣지 않습니다. 최신 브라우저 실제 클릭·레이아웃은 자동화 도구 오류로 미검증입니다. [시연 순서](demo-guide.md)를 제공하며 이 부분을 완료로 표시하지 않습니다.
